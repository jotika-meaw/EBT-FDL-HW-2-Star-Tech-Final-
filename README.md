# EBT FDL HW 2 - Star Tech Final

> A Star Tech-inspired product detail page for an MSI gaming monitor, built as a frontend web development assignment.

## 📌 Overview

This project recreates the look of a Bangladeshi tech-retail product page. It presents a single product — the MSI G2412V gaming monitor — with a category navigation bar, a product highlight block, and a full specifications table. The entire page is a single HTML file styled with inline CSS, which keeps it dependency-free and easy to deploy.

## ✨ Features

- Header bar with logo, search, offers, gadget-fast, account and PC builder shortcuts
- Category navigation (Server & Storage, Accessories, Gadget, Gaming, TV, Appliance)
- Product hero block with image, key features and "View More Info" link
- Complete specifications table: display size, type, panel, resolution, pixel pitch, surface, aspect ratio, brightness, contrast ratio and refresh rate
- Viewport meta tag so the page scales on mobile screens

## 🛠️ Technologies

- HTML5 with inline CSS styling

> No JavaScript or external stylesheets are used — the page is intentionally single-file.
